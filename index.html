Application en ligne

TP3 – Fahd Krachel

Cette page est servie par un conteneur Docker sur une machine virtuelle cloud. Elle a été construite et déployée automatiquement par GitHub Actions après un simple git push.

Du commit à la mise en ligne

  1. 1 Push Le code est envoyé sur la branche main de GitHub.
  2. 2 Build Le runner construit l’image Docker.
  3. 3 Registre L’image est publiée dans le registre local.
  4. 4 Déploiement Le conteneur remplace l’ancienne version.
  5. 5 En ligne L’application répond sur le port 80.

Infrastructure

Machine
VM Ubuntu 24.04 fournie par l’école
Conteneur
nginx:alpine, port 80
Registre d’images
Docker registry:2 sur la VM
Intégration continue
GitHub Actions, runner auto-hébergé
Déclencheur
Push sur la branche main
